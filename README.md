# PM Backlog & Roadmap Template

> **Illustrative sample.** All product names, numbers and dates below are fictional. No real company data is included.

A simple template for planning a digital health product: how I structure a backlog, score items, and turn them into a quarterly roadmap.

## What is inside

- `backlog.md`: example backlog with user stories and priority scores
- `roadmap.md`: example Now / Next / Later roadmap
- `prd-sample.md`: one-page PRD for a fictional feature

## How to use

1. Copy the files and replace the sample items with your own.
2. Score each backlog item with the formula in `backlog.md`.
3. Move the top items into the roadmap and review every quarter.
